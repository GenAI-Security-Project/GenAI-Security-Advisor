# Extracted text -- search index only, not a source

Everything under this directory is auto-generated by
`scripts/extract_pdf_text.py` (via `pypdf`) from the PDFs vendored elsewhere
in `corpus/`, and regenerated automatically by
`.github/workflows/extract-pdf-text.yaml` whenever a corpus PDF changes.

**This is not vendored content and is not in `MANIFEST.yaml`.** It exists
solely so the companion MCP server
([GenAI-Security-Advisor-MCP](https://github.com/GenAI-Security-Project/GenAI-Security-Advisor-MCP))
can full-text search PDF content, which its Cloudflare Workers free-tier
hosting can't do at request time (PDF parsing exceeds the Workers free
plan's 10ms per-request CPU budget, so it has to happen offline instead, not
live).

pypdf's extraction is not layout-aware -- tables, multi-column pages, and
figures often come out garbled or out of order. **Never treat this text as
citable.** Each file's header comment points back at its source PDF; read
that directly (or the MCP server's `get_resource` tool, which returns a
`raw_url` for the original) for anything that needs to be quoted precisely.

Do not hand-edit files here -- they're overwritten on the next extraction
run.
